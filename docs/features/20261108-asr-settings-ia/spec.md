# 语音识别设置页重排：识别方式、本机模型与在线服务

> 规格日期：2026-11-08。依据本地设计稿整理，业务实现尚未开始。
> 2026-11-08 追加：在线服务页获取转写模型，按用途从列表选择。
> 2026-11-08 追加：字幕转录并入语音识别设置，管理字幕只保留一个模型转录入口。
> 发布状态：已发布至 [GitHub issue #14](https://github.com/iron6909/loop-back/issues/14)，已应用 `ready-for-agent`。

## Problem Statement

现在打开「我的 → 语音识别」，同一组「字幕转录 / 跟读 / 复述」出现了两次：一次在「按用途识别」，一次在「在线语音服务」的在线模型与验证。用户得在两处之间对照，才能知道某个用途到底用什么、缺什么。

本机模型的下载、删除和单选又在下方的「语音引擎 / 本机模型」里，单选看起来像全局设置，实际只影响跟读；字幕和复述的模型选择藏在各自的用途弹窗里。在线服务占了大半页，但验证只是行尾一个图标，验证结果、缺 Key、未配置混在一起。在线模型还要逐个用途刷新目录或手填模型 ID；三个用途重复操作，用户还得记住模型 ID。管理字幕弹窗又并列提供「本地转录」和「在线转录」，和语音识别设置里的字幕本机模型各管一段，用户要在两个地方理解字幕怎么转录。

最终用户无法一眼回答四个问题：

1. 字幕、跟读、复述分别使用哪种识别方式？
2. 每个用途用的是哪个模型？
3. 这个用途现在能不能用；不能的话缺什么？
4. 补这一步要去哪里点？

## Solution

把页面按「用途决定方式 → 本机资源 → 在线资源」重排为三层：

- **识别方式**：三个用途各占一行，行内显示方式、模型和状态；每行只有一个入口，打开后只改当前用途。字幕转录在这里选择本机或在线（不提供系统），跟读与复述可选本机 / 系统 / 在线。管理字幕弹窗只保留一个「模型转录」动作，按这里的字幕选择执行。
- **本机模型**：变成纯资源库，列出三档模型、下载状态、占用和用途标签；不再用单选暗示「全局模型」，模型选择回到各用途详情里。页面级「语音引擎」卡片删除。
- **在线服务**：主页面只保留一条状态入口（服务类型、已配置 / 已验证），点进独立的「在线语音服务」页集中管理供应商、Key、按用途在线模型与验证。在线服务页提供「获取转写模型」按钮，三个用途共用同一份列表选择；自定义服务或目录不可用时仍可手填。

识别语义、偏好键、备份边界保持不变，不做数据迁移。

## User Stories

1. 作为学习者，我想在设置页一眼看到字幕、跟读、复述各自的方式与模型，以便判断当前配置能不能用。
2. 作为学习者，我想每个用途只有一个选择入口，以便不用在「按用途识别」和「在线语音服务」之间来回对照。
3. 作为学习者，我想在用途行上直接看到方式、模型与状态（已下载 / 未下载 / 已验证 / 尚未验证 / 不可用 / 设备自带），以便不进入详情就知道缺什么。
4. 作为学习者，我想点开某个用途时看到「只影响这个用途」的说明，以便修改跟读时不用担心改动字幕或复述。
5. 作为学习者，我想没有受影响的在途任务时立即应用修改，以便快速切换方式。
6. 作为学习者，我想有受影响的在途任务时先确认、再取消，以便不丢失未完成的结果。
7. 作为学习者，我想字幕转录也在这里选择本机或在线，与跟读、复述使用同一个入口，以便只在一个地方配置文件字幕的转录方式。
8. 作为学习者，我想跟读和复述在支持的平台上可以选择系统识别，以便使用设备自带能力。
9. 作为学习者，我想不可用的在线方式仍然显示并说明缺配置、缺 Key 还是未验证，以便知道下一步去补什么。
10. 作为学习者，我想在线方式只在该用途自己的能力验证通过后可选，以便不会被复用其他用途的验证误导。
11. 作为学习者，我想在本机模型区看到已下载模型、预估或实际大小、下载进度与失败原因，以便管理存储。
12. 作为学习者，我想下载、重试、取消和删除模型，行为与现有版本一致，以便不因改版丢失已有能力。
13. 作为学习者，我想看到每个模型被哪些用途正在使用（例如「字幕在用 · 跟读在用」），以便决定是否可以删除。
14. 作为学习者，我想在本机模型区看到总占用与模型来源，以便了解空间和下载渠道。
15. 作为学习者，我想在跟读使用系统识别时仍然能管理本机模型，以便字幕或复述继续使用本机模型。
16. 作为学习者，我想在线服务在主页面只显示一条状态摘要，以便页面不被供应商表单占满。
17. 作为学习者，我想点状态摘要进入「在线语音服务」页，以便集中配置服务地址、Key 和三个用途的在线模型。
18. 作为学习者，我想在线服务页显示未配置 / 缺少 API Key / 已保存尚未验证 / 已保存已验证，以便先判断整体状态。
19. 作为学习者，我想编辑供应商、Base URL 和 API Key，并在保存时得到地址校验和失败提示，以便正确保存。
20. 作为学习者，我想在在线服务页获取一次转写模型列表，然后在每个用途里从同一份列表选择，而不是手填模型 ID，以便快速匹配服务能力。
21. 作为学习者，我想每个用途单独看到验证结果（字幕可用 / 仅文本可用 / 词时间戳可用 / 尚未验证），以便知道这个模型能不能用于该用途。
22. 作为学习者，我想验证是一次明确的点击，并在首次上传前看到接收方、下游供应商和可能收费的告知，以便不被自动扣费。
23. 作为学习者，我想验证失败时只看到原因，不自动重试、不自动换服务，以便控制花费。
24. 作为学习者，我想修改服务地址、Key 或某个用途的在线模型时，被告知哪些在线任务会受影响，以便避免结果被静默丢弃。
25. 作为学习者，我想从在线服务页返回后回到语音识别设置，以便连续调整。
26. 作为学习者，我想本机、系统与在线三种方式互不覆盖：切到在线或系统后仍保留原来的本机模型，以便切回时不用重选。
27. 作为学习者，我想页面上不再出现「语音引擎」的全局后端单选，因为跟读方式里已经选过了，以便不再猜哪个设置生效。
28. 作为学习者，我想所有可点击行有足够大的触控区域，验证等操作有可读的文字或标签，以便单手操作和读屏使用。
29. 作为学习者，我想浅色与深色主题下都沿用现有卡片、间距和强调色，以便改版不突兀。
30. 作为学习者，我想离线时仍能打开设置、管理模型，以便没有网络也能调整本机配置。
31. 作为使用 Android 的学习者，我想只看到本机与在线两种方式，不看到不可用的系统识别，以便不被无效选项干扰。
32. 作为使用 Apple 平台的学习者，我想系统识别只出现在跟读与复述，不出现在字幕，以便符合平台能力。
33. 作为维护者，我想不改变偏好键、识别选择模型和备份边界，以便升级不迁移、不丢配置。
34. 作为维护者，我想下载、删除、验证与取消在途任务继续只有一个业务来源，以便后续切片不重复实现。
35. 作为学习者，我想在缺少 Key 时看到「获取转写模型」按钮不可用并说明原因，以便知道先补哪一步。
36. 作为学习者，我想获取失败或列表为空时仍能手动输入模型 ID，以便自定义服务或目录异常时不阻塞配置。
37. 作为学习者，我想在服务地址或 Key 改变后重新获取列表，以便不会选到旧服务的模型。
38. 作为学习者，我想获取目录只读取模型列表，不上传录音、不产生验证费用，以便安全地浏览模型。
39. 作为维护者，我想页面卸载或配置变化后丢弃迟到的目录结果，以便旧请求不会覆盖新配置。
40. 作为学习者，我想管理字幕弹窗只显示「模型转录」和「本地上传」，不再并列本地与在线，以便不用在弹窗里重复选一次方式。
41. 作为学习者，我想「模型转录」按语音识别设置里的字幕方式执行，以便设置和弹窗不会给出两个不同的结果。
42. 作为学习者，我想在管理字幕弹窗看到当前字幕方式和模型（例如「本机 · Whisper Small」），以便开始前确认会用哪一种。
43. 作为学习者，我想字幕在线方式未通过片段时间戳验证时看到原因，并知道去语音识别设置修改，以便不会在两个入口之间猜。
44. 作为学习者，我想本地上传字幕的入口不受合并影响，以便已有字幕文件仍可直接导入。
45. 作为学习者，我想字幕切到在线后仍保留原来的本机模型，切回本机时不用重选，以便来回切换不丢配置。
46. 作为维护者，我想合并只改变入口和路由，在线字幕任务、分块、续试、费用提示和历史结果的行为保持不变，以便不借改版改动转写协议。

## Implementation Decisions

### 页面结构

- 识别设置页改为三个纵向分组：**识别方式**、**本机模型**、**在线服务**。说明文字只保留一条，放在「识别方式」之前。
- 删除页面级「语音引擎」卡片和其中的本机 / 系统后端单选。`AsrBackend` 状态继续存在：它由「跟读」用途的本机 / 系统选择驱动，Android 仍固定本机；设置页入口旁的后端摘要本轮不改。
- 「识别方式」卡片固定三行：字幕转录、跟读、复述。每行显示用途名、方式与模型摘要、状态，右侧保留进入用途详情的入口。
- 状态按用途推导：
  - 本机：按所选档位导出已下载 / 未下载 / 下载中 / 下载失败；
  - 系统：设备自带；
  - 在线：已保存配置且该用途的能力记录满足要求（字幕需要片段时间戳，跟读 / 复述需要文本）时显示已验证；有记录但不满足时显示不可用；没有记录时显示尚未验证；没有配置时显示未配置。
- 字幕转录在用途详情里选择本机或在线，不提供系统识别；在线必须是字幕可用模型（能返回可用的片段时间戳）。在线模型与 Key 仍在「在线语音服务」配置，用途详情只负责选择方式和本机模型。

### 用途详情

- 保留现有底部弹窗交互，三个用途的标题下都增加一句范围说明：只影响当前用途。
- 跟读与复述保留现有方式顺序、在线不可选原因、能力验证门槛和在途任务确认逻辑，不改变任何选择语义。
- 字幕的方式列表为本机识别与在线识别；在线不可用时仍列出并说明缺配置、缺 Key、未告知或未通过片段时间戳验证。字幕不出现系统识别。
- 本机方式下继续列出三档模型供当前用途选择；选中未安装模型的实际下载/提示仍由各业务入口的既有门控负责。
- 在途任务确认继续复用现有的统一入口，拒绝时配置与任务都保持不变。

### 字幕的单一入口与管理字幕弹窗

- 字幕在线准入必须以片段时间戳能力为准，不能沿用「有文本即可」的练习门槛。在线可用性与阻断原因共用同一份判断：字幕的异步可用性检查也传入 segments 要求，避免纯文本模型被列为可选。
- 字幕方式继续使用现有偏好键（本机 / 在线），不新增迁移。旧版本在管理字幕弹窗里选在线不会写入这个偏好；升级后字幕默认仍为本机，第一次选择在线在语音识别设置里完成。
- 管理字幕弹窗的选项从「本地转录 / 在线转录 / 本地上传」合并为「模型转录 / 本地上传」；播客可下载字幕时仍多一项「下载播客字幕」，保持现有顺序和下载行为。
- 「模型转录」是唯一转录入口，显示当前字幕方式与模型摘要（「本机 · Whisper Small」或「在线 · whisper-1」），不提供本地 / 在线切换。旁边或下方只保留一句静态提示：方式与模型在语音识别设置中修改。用户离开弹窗去设置是唯一修改入口，弹窗不写偏好。
- 选择「模型转录」后按当前字幕选择路由：本机走现有本机转写与模型就绪门控；在线走现有在线字幕任务。两种情况的「开始转录」、进度、取消、失败原因、可续试提示、可能重复计费提示、覆盖确认和历史字幕保护都保持现有行为。
- 当前字幕选择为在线但准入不通过时，「模型转录」与主按钮禁用并显示阻断原因；「本地上传」仍可用。当前选择为本机但模型未下载时，保持现有下载提示，不改成在线。
- 保留「字幕转录选项」（语言、短句合并）在模型转录被选中时显示；播客下载和本地上传不显示这些选项。现有自动语言提示、重试未完成和任务进度继续复用。
- 删除弹窗内本地 / 在线两个选项及相关文案；新增「模型转录」文案和「在语音识别设置中修改」提示。更新字幕用途详情里指向管理字幕弹窗的旧提示，避免再让用户去弹窗选在线。
- 不改在线字幕任务管理、分块规划、续试、费用上报、字幕提交事务和历史结果；本轮只改入口与路由。

### 本机模型资源库

- 本机模型卡片始终显示，不再依赖跟读后端是否为本机；因此跟读使用系统识别时，字幕与复述仍可下载、删除模型。
- 取消卡片内的模型单选。模型选择只发生在各用途详情中，避免「这个单选到底改了谁」。
- 每行显示模型真实名称、推荐标记、大小、下载状态与用途标签。用途标签只标记当前方式为本机且档位匹配的用途。
- 已下载行保留删除入口；下载中保留取消；失败保留重试；未下载新增「下载」入口。下载动作复用现有下载与校验管线，只更新安装状态；只有当前档位是跟读使用中的档位且后端为本机时才初始化离线引擎，避免在系统识别下无谓加载引擎。
- 分组标题右侧显示已下载模型总占用；卡片底部保留模型来源入口，点开后用现有的两个来源选项与说明。
- 分组标题提供「删除所有已下载模型」的次要操作，继续使用现有确认文案与删除规则（当前使用中的跟读档位仍由既有规则保护）。

### 在线服务入口与二级页

- 主页面「在线服务」只保留一张入口卡：云图标、服务名称、状态摘要、进入箭头。状态文案与服务页共用同一份推导，不在两处各写一套。
- 新增「在线语音服务」页，AppBar 标题为「在线语音服务」，正文把现有语音服务配置区作为主体，去掉重复的卡片内标题行。
- 服务页分为连接配置与按用途在线模型两部分：
  - 连接配置：供应商、Base URL、API Key 三行，沿用现有编辑对话框、地址校验、保存失败提示与「Key 不回显」规则。
  - 按用途在线模型：分区标题右侧提供「获取转写模型」按钮；三个用途各一块。每块第一行是用途名与模型选择入口，第二行是能力状态与「验证模型」文字按钮。
- 「验证模型」使用文字按钮而不是行尾图标；无配置、无 Key、无模型或验证进行中时禁用；验证进行中显示进度状态。成功后的能力摘要与费用提示沿用现有规则。
- 获取目录、保存、验证失败与地址错误的提示都留在触发区域附近，不静默吞掉。
- 首次验证前的上传告知、按用途能力记录、费用未知提示、失败不自动重试、配置变化后旧验证失效、修改配置前取消受影响在线任务，全部保持现有行为。
- 主页面不发起任何网络请求；打开设置页、进入在线服务页、保存配置都不发请求。获取目录只在用户点击「获取转写模型」后发生；验证只在用户点击「验证模型」后发生。

### 获取与选择在线模型

- 「获取转写模型」只在在线服务页出现，且只对 OpenRouter 显示；自定义服务不提供目录接口，因此隐藏该按钮，用途模型行直接进入手填。
- 按钮在已保存配置与 API Key 时可用；缺配置或 Key 时禁用并说明原因。打开页面时不自动获取。
- 点击后拉取一次 OpenRouter 的转写模型目录，显示加载状态并在加载中禁用按钮。成功后把列表保存在当前页面会话，显示已获取数量，并允许重新获取。
- 三个用途共用同一份列表。用途的模型行改为选择入口：点击打开可滚动的模型列表，当前模型有选中标记；选择后只保存该用途的在线模型。
- 列表底部保留「手动输入模型 ID」。获取失败、列表为空、自定义服务或尚未获取时，用途模型行直接进入手填。
- 获取到的列表不持久化。供应商、根地址或 Key 变化时清空列表，避免把旧服务的模型选到新服务；当前已保存的模型不因列表清空而改变。
- 获取请求是只读的目录查询，不发送测试音频、不产生能力验证费用、不写能力记录。
- 页面卸载或配置变化后返回的旧目录结果必须丢弃；不得覆盖新列表或把旧模型写进配置。
- 选择模型仍走现有的保存与在途任务确认；一次只改当前用途。
- 新增「获取转写模型」「已获取 N 个模型」等中英文文案；目录失败与空列表继续使用现有提示。移除逐用途刷新入口后，清理不再使用的刷新文案。

### 状态、数据与兼容

- 不新增或修改 SharedPreferences 键、识别选择模型、语音配置结构、能力记录结构、备份字段或数据库结构，不需要迁移。
- 复用现有识别设置、离线 ASR 设置、语音配置、语音能力 provider；不复制状态，不新增第二份「当前模型」。
- 删除页面级后端单选不改变持久化语义：跟读选择本机/系统时仍通过现有入口写 `AsrBackend`，其他平台行为不变。
- 所有新增界面文案进入中英文 ARB；能复用现有 key 的复用，不为同义文案新增重复 key。

### 视觉与可访问性

- 沿用现有主题：页面浅灰背景、16 圆角白色卡片、品牌蓝色分组标题、现有语义色（成功 / 警告 / 错误）。
- 列表行使用标题 + 次要说明的两行结构；用途状态用文字加点状标记，不只靠颜色区分。
- 所有可点击行、文字按钮和图标按钮触控区域至少 44dp；图标按钮必须有语义标签。
- 主页面在 390 宽度下不出现横向溢出，卡片内容允许纵向滚动。

## Testing Decisions

好的测试只验证用户可见行为和状态流转：打开页面看到什么、点击后发生什么、provider 收到什么请求。不断言私有方法、精确颜色、字号或无关的卡片数量。

### 测试边界（seams）

- **最高边界：识别设置页 widget 测试**。从一个入口驱动整页：三个用途行与状态、用途弹窗、本机模型操作、在线服务入口与导航。
- **在线语音服务区 widget 测试**：沿用现有「语音服务配置区」测试边界，覆盖连接配置、按用途模型、验证与在途任务；新页面只增加 AppBar 与导航，不为页面壳新增独立测试边界。
- **管理字幕弹窗 widget 测试**：沿用现有弹窗测试边界，覆盖合并后的模型转录、本地上传、在线阻断与任务路由。
- **Provider 状态测试**：继续使用现有识别设置、离线 ASR 设置、语音配置与能力验证测试；本轮不新增数据 seam。

### 需要覆盖的行为

1. 三个用途行展示各自的「方式 · 模型」与正确状态；字幕提供本机 / 在线方式（在线按片段时间戳能力可用）、不出现系统方式；跟读与复述在支持平台出现系统方式。
2. 点击用途行打开详情；详情显示「只影响当前用途」；修改只写当前用途，其他用途不变。
3. 有在途任务时先确认；拒绝保留配置与任务；接受后取消受影响任务并应用变更。
4. 在线不可用时仍列出该方式并显示具体阻断原因（缺配置 / 缺 Key / 未告知 / 未验证 / 模型不适配）。
5. 本机模型区在本机与系统后端下都可见；下载、取消、重试、删除分别产生正确的 provider 调用与可见状态。
6. 未下载模型可从本机模型区直接下载；在系统后端下下载不会切换跟读选择或把后端改成本机。
7. 用途标签只标记当前使用该档位的本机用途；总占用与模型来源入口正确。
8. 主页面在线入口显示未配置、缺 Key、未验证、已验证状态；点击进入在线服务页，返回后回到设置页。
9. 在线服务页显示连接配置与三个用途块；获取按钮的启用/禁用、加载、成功数量、失败和空列表状态正确；三个用途共用同一份列表，选择只写当前用途。
10. 首次验证出现上传告知；取消不发请求；确认后只发一次；费用与能力结果正确显示；失败显示原因且不自动重试。
11. 修改服务地址、Key 或某用途在线模型时，受影响的在线任务先确认；本机 / 系统任务不受影响。
12. 现有 provider 状态测试全部保持通过，确认没有偏好键、能力记录或备份边界变化。
13. 缺 Key 时获取按钮禁用；自定义服务隐藏获取按钮，用途模型行仍进入手填。
14. 获取成功后三个用途都能从同一列表选择；获取失败或空列表时仍可手填；服务地址、Key 或供应商变化后列表清空。
15. 获取目录只调用目录客户端一次，不上传测试音频、不写能力记录、不产生验证费用。
16. 配置变化或页面卸载后返回的旧目录结果被丢弃，不覆盖新列表或配置。
17. 字幕用途详情显示本机 / 在线，在线在缺配置、缺 Key、缺告知或没有片段时间戳能力时禁用并说明原因；不显示系统识别。
18. 选择字幕在线后选择被持久化，主页面字幕行显示在线模型；切回本机仍保留原来的本机模型。
19. 管理字幕弹窗只有「模型转录」和「本地上传」（播客多一项下载）；模型转录显示当前字幕方式与模型，不显示本地 / 在线切换。
20. 字幕选择本机时，模型转录走本机任务并使用字幕自己的本机模型；选择在线且准入通过时，走在线任务；不要求本机模型就绪。
21. 字幕选择在线但准入不通过时，模型转录与主按钮禁用并显示原因，本地上传仍可用；不会静默改成本机。
22. 本地上传、覆盖确认、语言 / 短句合并、在线任务进度、失败原因、可续试与重复计费提示保持现有行为。
23. 纯文本能力验证不能让字幕在线可选；字幕在线可用性必须检查片段时间戳。

### 既有测试调整

## Out of Scope

- 把本机模型统一成一个全局档位。设计稿中的全局单选被否决：字幕转录需要更高精度档位，而跟读评分需要更轻的档位，二者按用途独立是既有决策。
- 重做管理字幕弹窗中语言、短句合并、覆盖确认、本地上传或播客字幕下载的交互；本轮只合并本地 / 在线转录入口。
- 修改识别选择的数据模型、偏好键、迁移、备份恢复和凭据存储。
- 修改在线转写、能力验证、模型目录接口协议、分块续试、费用上报等业务协议或执行路径；也不为自定义服务新增目录接口。
- 修改本机模型的下载来源、校验、安装目录或 native 引擎行为。
- 重做「我的」设置页的语音识别入口摘要，或调整其他设置页面。
- 全面重做主题、字体或深浅色视觉规范。
- 新增设备、Maestro 或真机验收证据。
