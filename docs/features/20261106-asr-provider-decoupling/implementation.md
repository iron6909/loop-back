## I4：在线转写与能力验证

- [ ] 使用现有 Dio 依赖实现专用 multipart 请求；发送文件、模型、英语参数及用途需要的输出格式，不复用 Chat Completions 请求体或权益拦截器。
- [ ] 文本用途请求 JSON 文本；字幕请求 `verbose_json` 和片段时间戳。词时间戳仅对已确认支持的配置请求；能力测试可验证词时间戳，但不得对正式用户音频自动反复变换参数重发。
- [ ] 严格校验文本、片段起止和可选词时间戳，转换为项目使用的结果结构。模型列表只证明模型存在；每次正式结果仍须校验。
- [ ] 用有许可的随包英语短音频执行用户主动触发的测试，记录文本/片段/词能力、验证时点和非秘密配置身份。验证状态本机保存，正常重启不要求重复付费测试；配置变化和备份恢复使相关验证失效，不存储 Key 的明文或派生摘要作为身份。
- [ ] OpenRouter 列表刷新使用其 STT 目录接口，失败不妨碍手填；自定义地址不强制支持 `/models`，也不向其他主机转送凭据。
- [ ] 区分未配置、401、402、404、429、413、格式/能力不支持、5xx、超时、取消及空结果；无自动付费重试或供应商/模型回退。保存有限的用量和可用费用，未知不按零计费。

回归：注入假 transport 检查真实请求形状、返回映射、超时/取消和严格校验；测试请求的成功不写用户字幕。真实供应商调用不进入普通自动化测试。

## I5：来源信息与原子提交

- [ ] 在实施时的最新数据库版本上追加迁移；原字幕、学习记录、收藏和来源值不改写。更新条目读写/序列化和相关界面，让在线产生的估时字幕仍显示正确提示，不能仅凭 `source=online` 宣称逐词精确。

- [ ] 数据库提交成功后再刷新内存状态。提交前取消不得写入；提交已开始则以事务完成结果为准，避免 UI 报取消但实际上已覆盖。

回归：事务中途失败、元数据更新失败、提交前取消、识别期间用户导入字幕、历史整数映射、未知来源与估时提示。用真实内存数据库验证；原失败路径应先写回归再修复。

## I6：分块、续试与资源生命周期

- [ ] 在既有音频转换边界增加有界区间提取与取消，保留原始媒体。优先复用已支持的 16 kHz 单声道转换；输出格式需在目标服务上验证。
- [ ] 同时限制单块字节数和音频时长，留出 multipart 请求余量。首个工程验证目标为约 2 分钟一块，以实际模型时延/上游限制校准并固定；这是实现参数，不新增用户配置项，也不把 30 秒本地推理窗口当在线限制。
- [ ] 切点优先选择邻近静音；必须硬切时保留短重叠。字幕合并使用绝对时间偏移和边界局部对齐，不对全文做字符串去重，防止误删真实重复句。需要分块的纯文本录音同样验证边界拼接；不能靠均分时长制造字幕。
- [ ] 同一任务顺序上传；成功块保存结果、时间偏移和输入/配置身份，释放不再需要的音频临时块。失败停在当前块，重试仅从未成功块继续，禁止混入其他输入或配置的结果。
- [ ] 任务管理器在进程内拥有检查点；关闭/重开弹窗不清除可续试的失败任务。主动取消、删除目标材料或 D13 配置变更结束任务并清理临时结果；下次启动清理本模块遗留临时文件，不声称可以恢复旧任务。
- [ ] 取消应传到转换/上传/响应等待，取消后不再开始下一块；不承诺撤回供应商已处理请求的费用。所有块校验并合并成功后才进入 I5 提交。

回归：两块成功一块失败后只重试第三块、重开弹窗仍可续试、真实重复句与跨块单词、取消不发后续请求、变更配置不能复用旧块、临时清理不删除源文件。采用可控 Future/假 transport，不用任意 sleep 让测试通过。

## I7：三条业务接线

- [ ] 字幕入口根据用途快照路由；本机继续 Whisper 滑窗、完整句还原和可选短句合并，在线复用后处理与 I5 提交。选择在线不经过本地模型/VAD 安装门控。
- [ ] 跟读在线模式仅在停止录音后上传；录音后端使用正确的录音模式，避免系统识别、离线识别与在线识别同时处理同一最终结果。系统实时反馈按原平台能力保留，最终转写来源与所选模式一致。
- [ ] 复述按自己的配置执行；同 attempt 且识别来源匹配时复用有效文本，否则按当前选择识别。结果包含实际识别身份，不能仅用文件路径判断可复用。
- [ ] 识别失败不发起复述评估；评估继续由独立文字 AI 服务处理。实际文本相同且既有评估缓存身份匹配时可复用评分，不为来源标签变化无条件重复请求。
- [ ] 有效历史结果保持展示；显式重新识别才生成新结果。监听语音配置变更以作废在途请求，保留现有 attempt/session/generation 守卫。

回归：三用途分别走正确分支、在线无本地模型仍可用、现有系统/本机行为、复述配置实际生效、旧转写不冒充新模型、识别失败无评估请求、旧结果不覆盖新 attempt。
