# UI Specification: 供应商直连与本地化改造

本规格服务 [spec.md](./spec.md)，只补充布局、呈现状态与交互；行为与数据约束以 `spec.md` 为准，视觉取值以 [DESIGN.md](../../../DESIGN.md) 为准。冲突时优先级为 spec → 本文件 → DESIGN.md。

## Overview

四个界面区域：

1. **AI 服务页**：供应商配置、连接验证与用量卡的唯一入口。
2. **用量卡**：随当前供应商切换的只读展示，含失败与降级状态。
3. **导入本地合集**：复用现有导入弹窗，新增「从文件夹导入」来源。
4. **历史社区合集只读态**：停止同步后的表达与缺失媒体的禁用。

已确认移除：远端合集发现页、网盘导入入口、商店网页结账兜底、自更新提示。

## Structure

```
设置 (Settings)
└─ AI 服务 (新页面)
   ├─ 用量卡
   ├─ 供应商卡 → 供应商选择 / Base URL / 模型 / API Key / 连接验证
   └─ 关于卡 → 提示词版本（只读）

资源库 → 我的合集
├─ 合集卡片（含「已停止同步」徽标）
├─ 顶栏操作 → 导入本地合集
└─ 合集详情 → 音频行（缺失媒体时禁用）

我的合集 → 导入本地合集
└─ 导入弹窗（复用 ImportAudioFlowSheet）
   ├─ 来源步骤：新增「从文件夹导入」
   ├─ 选择确认步骤（复用 ImportAudioSelectionList）
   └─ 完成汇总步骤
```

关键路径：配置供应商 → 连接验证 → 回学习页使用 AI；以及选目录 → 确认列表 → 导入完成。

## Screens

### S1 AI 服务页

入口：设置 → AI 服务。单列滚动，卡片间距 `m`。

```
┌ AppBar  AI 服务 ────────────────────────┐
│ ┌ 用量卡 ─────────────────────────────┐ │
│ │ DeepSeek · 账户余额                 │ │
│ │ ¥110.00 CNY                         │ │
│ │ 赠送 ¥10.00 · 充值 ¥100.00          │ │
│ │ 更新于 11:20                 [刷新] │ │
│ └─────────────────────────────────────┘ │
│ ┌ 供应商 ─────────────────────────────┐ │
│ │ 供应商        DeepSeek          ›   │ │
│ │ Base URL      https://api.dee…  ›   │ │
│ │ 模型          deepseek-flash    ›   │ │
│ │ API Key       •••••••• 已保存   ›   │ │
│ │ 连接验证      未验证      [测试]    │ │
│ └─────────────────────────────────────┘ │
│ ┌ 关于 ───────────────────────────────┐ │
│ │ 提示词版本                    v1    │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

- 未配置时：用量卡替换为引导卡「尚未配置 AI 服务」，主按钮「配置供应商」；供应商卡仅「供应商」一行可用。
- 「供应商」打开选择对话框，三项：`DeepSeek`、`OpenRouter`、`自定义`。选择预设时 Base URL 与模型自动填入可编辑值；选择「自定义」时 Base URL 为空并聚焦。
- Base URL / 模型：点击弹出单行输入对话框，保存前做 URI 合法性校验，非法时对话框内联报错且不关闭。
- API Key：点击弹出密码输入对话框；已保存时显示「已保存」而不是任何形式的明文或掩码回显。清空并保存等于删除 Key。
- 「连接验证」按钮：进行中禁用并显示「测试中…」，结果以内联文字显示（成功 / 鉴权失败 / 地址或模型不存在 / 网络超时），不使用 SnackBar，便于反复查看。
- 「提示词版本」只读展示，不提供编辑。

### S2 用量卡

固定卡片，标题为「供应商名 · 数据范围」。数据范围必须显式标注：`账户余额` / `Key 预算` / `套餐窗口`。

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 卡片内骨架行，保留卡片高度，不显示 0 |
| 套餐窗口（OpenCode Go） | 三行，每行：窗口名（5 小时 / 每周 / 每月）+ 已用百分比 + 重置时间；剩余最少的有效窗口置顶并加粗 |
| 已限额 | 该行显示「已限额」文字 + 警告图标，即使百分比显示 99 |
| 金额余额（DeepSeek） | 主值 = 金额 + 币种；多币种时每种一行，不合并；有值时展开「赠送 / 充值」两行 |
| 仅 Key 预算（OpenRouter） | 主值 = 剩余预算 + 周期；另起一行注明「账户余额不可查询」 |
| 无权限 | 「账户余额未授权查询」+「Key 未设预算」二选一或同时展示 + 「打开供应商控制台」链接 |
| 不支持查询 | 「该地址不支持用量查询」，不展示任何数字 |
| 刷新失败（有旧数据） | 保留旧值，底部加一行「更新失败 · 上次 11:20」+ 重试按钮 |
| 从未成功 | 卡片正文「暂无法获取」，附重试按钮 |

- 任何状态都不隐藏「刷新」以外的其他页面元素，也不阻止 AI 请求。
- 刷新按钮在请求中禁用并转为旋转图标；卡片高度不因状态切换跳动（最小高度固定）。

### S3 导入本地合集

入口：我的合集顶栏操作「导入本地合集」。复用 `ImportAudioFlowSheet`，新增来源项「从文件夹导入」（仅在从合集入口进入时出现）。

选择确认步骤复用 `ImportAudioSelectionList`，额外规则：

- 头部显示「已选 N 个文件 · 总大小」。
- 每行：媒体图标、文件名、同名字幕 `CC` 徽章、文件大小、状态图标。
- 汇总区在既有「成功 / 重复跳过 / 失败」之后追加两行：`忽略子目录 N 个`、`不支持格式 M 个`（M 为 0 时不显示）。
- 目录为空或全部被过滤：停留在来源步骤，显示内联错误「该文件夹里没有可导入的音频」，不创建合集。
- 导入进行中禁止关闭弹窗（复用现有 `PopScope` 行为），并显示逐文件进度。

### S4 历史社区合集只读态

- 合集卡片：保留原有社区角标，追加灰色徽标「已停止同步」。
- 合集详情顶部：一条说明条「该合集来自旧版社区，内容已不再更新」。
- 音频行：媒体文件缺失时置灰并显示「媒体未下载」，点击弹提示说明原因；已下载媒体的条目保持可进入学习。
- 不显示远端专属字段（难度徽标、地区镜像、发布者）；`remoteId` 不展示。

## Interactions

- **指针**：卡片与行可点击区域覆盖整行；悬停只改变背景色，不承载必要信息。
- **触屏**：所有可点行有效高度 ≥ 44dp；行内小图标按钮（刷新、重试、删除）实际点击区扩到 44dp。
- **键盘**：Tab 顺序为「用量卡 → 刷新 → 供应商 → Base URL → 模型 → API Key → 连接验证 → 提示词版本」；对话框 Esc 关闭并把焦点还给触发控件；输入对话框 Enter 提交。
- **弹窗**：单行输入对话框点遮罩关闭并丢弃未保存输入；连接验证无弹窗。
- **导入弹窗**：拖拽手柄与返回手势在导入中禁用；完成后关闭回到「我的合集」并定位到新建合集。

## Edge cases

- **超长 Base URL / 模型名**：行内单行省略，末尾保留 `›`；点开对话框可看完整值。
- **用量卡数字极长**：金额右对齐，超出以省略号截断，不换行撑高卡片。
- **多币种超过 3 种**：默认显示前 3 种，追加「查看全部」展开。
- **Key 未配置时点连接验证**：按钮禁用并显示「请先填写 API Key」。
- **目录内文件全部重复**：汇总显示「全部为重复项」，不新增合集条目，但仍创建合集并提示。
- **导入过程中退到后台**：保持进行中状态，返回时按实际进度刷新。
- **只读合集中的音频被删除**：显示「媒体未下载」而不是播放失败。

## Accessibility

- 状态含义依赖「图标 + 文字」双通道；用量卡的已限额、导入行的跳过/失败均带文字标签。
- 进度使用 `LinearProgressIndicator` 并在相邻文本给出当前文件与百分比；进度更新通过状态语义暴露，不移动焦点。
- 所有输入框保留可见标签（不用 placeholder 代替）；错误信息与字段关联，内联显示。
- 图标按钮具备可读名称；纯装饰图标对辅助技术隐藏。
- 不依赖 tooltip（全局已禁用）；`DESIGN.md` 的该约束在此重申。
- 对比度按 `DESIGN.md` 取值在实现后实测；本规格不声称已验证渲染结果。
