# 发音包在来源无法核实时的公开再分发与标注

2026-11-10，依据[词典与发音库方案 D8、D10、D11](../features/20261110-dictionary-pronunciation-decoupling/plan.md)确认：发音包内容字节不变地重托管到自建公开源；由于音频来源无法核实（特征文件名无任何公开数据集指纹），界面只标注托管仓库，不标注第三方来源与许可。

发音包是词典查词优先播放的预录单词发音；继续留在 EchoLoop CDN 违背全部资源去耦的目标，但公开再分发一份来源不明的音频在许可上不可辩护，也不能在界面虚构来源归属。选择如实标注：仓库卡片与应用界面均只写「由 Echo Loop 维护的托管仓库」，不声明第三方许可，保留 2026-11-10 制品解剖与检索无果的记录作为证据；数据重建项目若更换可核实来源的音频，再补充真实来源与许可标注。

此决策已接受，业务代码尚未实施；不据此改动历史安装或自动更换音频内容。
