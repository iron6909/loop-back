# 语音识别与文字 AI 分别持有供应商配置和凭据

2026-11-07，依据[语音识别方案 D3、D8](../features/20261106-asr-provider-decoupling/plan.md)确认：语音与文字 AI 使用独立的配置和安全凭据存储，各自管理配置变更、请求作废及凭据清除。语音内部只保留一份在线服务地址和 Key，字幕、跟读、复述分别选择识别方式与模型。

共享文字服务的配置槽会让用户修改语音地址或清除语音 Key 时同时影响翻译、讲解和聊天；自动共享 Key 还会增加撤销和备份恢复的隐式关系。选择独立存储的代价是同一 Key 用于两类服务时需分别填写，但能保持两个服务的设置和失败边界清楚。备份不得包含任一 Key，恢复必须同时覆盖两份凭据的清除与失败回滚。

此决策已接受，业务代码尚未实施；不据此修改历史识别结果或自动重发请求。
