# Domain docs

本仓库采用单领域布局：
- 根目录 GLOSSARY.md：领域术语。
- docs/adr/：架构决策。

## 读取规则

探索业务代码或编写规格前，读取 GLOSSARY.md，
以及与当前任务有关的 ADR。

文档不存在时继续任务；由 domain-modeling 在术语或决策
明确后按需创建，不预先生成空文档。

## 使用规则

需求、票据、设计、代码命名与测试描述使用术语表中的用语，
避免使用术语表明确排除的同义词。

发现真实术语缺口时，通过 domain-modeling 补充。
新方案与既有 ADR 冲突时，明确指出冲突和重新讨论的理由，
不静默覆盖已接受的决策。
