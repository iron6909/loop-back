# Triage labels

技能中的标准角色与本仓库标签保持同名。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给代理实施 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不予处理 |

需要应用某个分流角色时，使用此表映射。
复用已有同名标签，仅创建缺失标签。
