# LoopBack 品牌手册

**听进去，说出来，循环往复。**

LoopBack 是一款围绕「音频输入 → 句子级学习 → 间隔复习 → AI 辅助」的英语听说训练 App。名字取自信号术语 *loop back*（输出回到输入端）：在英语学习里，听是输入，说是输出，间隔复习让学过的内容一次次回到面前——听说与复习构成同一个闭环。

## 设计原则

1. **干净现代，彩色点缀**：浅灰页面背景 + 白色卡片浮起，品牌蓝负责选中与重点，语义色只做小面积点缀（参考 Learna AI 风格）。
2. **品牌蓝为主，金色克制**：大面积金色显廉价，CTA、选中态统一品牌蓝，金色仅用于皇冠图标与推荐徽标。
3. **深色 = 纯黑分层**：页面背景纯黑，卡片/AppBar/底栏近黑浮起，浮层逐级提亮，AMOLED 省电且保留层次。
4. **一个闭环标记**：所有品牌触点使用同一个「回环 + 声波」标记，不另造图形语言。

## 字体

无自研字体，使用系统默认 UI 字体（Android Roboto / iOS SF Pro / Windows Segoe UI / macOS SF），Material 3 字阶：

| 样式 | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| title | 17px | 24px | 700 | AppBar 标题 |
| button | 16px | 24px | 600 | 按钮文字 |
| body | 14px | 20px | 400 | 正文 |
| label | 12px | 16px | 400 | 标签、badge；导航标签 12px w600 |
| caption | 11px | 16px | 400 | 时间戳、次要信息 |

## 标记（Logo）

LoopBack 标记 = **回环 + 声波**：

- 一条 300° 的回环弧线，右上留 60° 缺口，箭头回转指向缺口——「说出去的话，再听回来」；
- 环内三根声柱（84 / 144 / 104 高，44 宽，全圆角），是听（输入）与说（输出）；
- 环半径 148、线宽 56（≈环半径的 38%），声柱全圆角（rx = 半宽）。

几何以 512 画布为基准，全部取值来自 `brand` 色板。构造说明：

- **App 图标**：512×512 全出血方形，背景 = `brand-active → brand → brand-deep` 对角渐变，标记白色。不得自加圆角或透明（Android / iOS 启动器自行加遮罩）。
- **单色标记**：`brand` 蓝画在透明底上，用于应用内（启动屏、关于页、水印），最小显示 24px，周围留白 ≥ 标记宽度的 20%。
- 不做描边版本、不做反白之外的第三色版本。

## 间距与圆角

间距 4 档递增（×2）：`space-1` 4 · `space-2` 8 · `space-3` 16 · `space-4` 24 · `space-5` 32。

| Token | 值 | 用途 |
| --- | --- | --- |
| radius-sm | 12px | 输入框、列表项、SnackBar |
| radius-md | 16px | 卡片、按钮（Elevated/Filled/Text/Outlined 统一） |
| radius-lg | 18px | 弹出菜单 |
| radius-xl | 20px | 对话框 |

按钮「完成/继续」并排时必须同一圆角档（radius-md），不得混用胶囊与圆角矩形。

## 来源与同步

色彩、间距、圆角取自 `lib/theme/app_theme.dart`（`AppTheme` / `AppSpacing` 常量），字阶取自 Material 3 默认值。本系统为手工同步，无自动同步管线；代码中改动品牌常量后需人工回写本手册与 `tokens.json`。
