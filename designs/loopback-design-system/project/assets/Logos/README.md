# Logos

LoopBack 的标识文件。两者共用同一构造：300° 回环（右上 60° 缺口、箭头回转）+ 环内三根声柱。

| 文件 | 用途 |
| --- | --- |
| `loopback-app-icon.svg` | App 图标：512×512 全出血方形，`brand-active → brand → brand-deep` 对角渐变背景，标记白色。启动器遮罩由系统加，本文件不画圆角。 |
| `loopback-mark.svg` | 单色标记：`brand`（#1976D2）画在透明底，应用内使用（启动屏、关于页、水印）。 |

使用规则：

- 最小显示 24px，周围留白 ≥ 标记宽度的 20%。
- 白色版只允许出现在品牌渐变/品牌蓝底上；单色版只允许 `brand` 蓝，不做其他色。
- 禁止：拉伸变形、加描边、加阴影、把声柱改成文字或图标、旋转超过 0°。
